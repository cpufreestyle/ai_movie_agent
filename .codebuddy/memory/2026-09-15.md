## 环境坑：本机 7897 代理已不通 GitHub，需直连
- 现象：`git push` 报 `schannel: failed to receive handshake`；换 `http.sslBackend=openssl` 报 `unexpected eof while reading`。
- 排查：`curl.exe -x http://127.0.0.1:7897 https://github.com` → 000（代理已失效）；`curl.exe https://github.com` → 200（直连通）。
- 解法（不改 git config，按次覆盖）：`git -c http.proxy= -c https.proxy= push origin main`。
  注意：`git ls-remote` 同样要带覆盖才不报错；PowerShell 里 `curl` 是 Invoke-WebRequest 别名，要用 `curl.exe`。

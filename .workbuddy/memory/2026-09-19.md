# 2026-09-19

## 画质增强 · 第二轮优化（模型真实性 + 客观度量）
- **发现「假成功」陷阱（P0）**：动漫默认推荐的 `RealESRGAN_x4plus_anime_6B.pth` 本机
  `models/upscale_models` 里**根本没有**（只有 `4x-UltraSharp.pth`）→ 超分阶段因权重缺失
  失败 → 被上层「阶段失败就跳过」静默吞掉 → 用户以为做了超分其实只重编码。
- **新增 `agent/comfy_models.py`**：一律查 `/object_info` 拿真实 COMBO 清单，缺失即回退到
  真实存在的权重 + 明确告警。**别再信任纸面模型名**。
  - 坑1：urllib 会走环境代理去访问 127.0.0.1 → 必须 `ProxyHandler({})`（否则查到空清单）。
  - 坑2：ComfyUI COMBO 有**两种**返回形态：`['COMBO',{'options':[...]}]`（UpscaleModelLoader）
    与 `[[...],{'default':...}]`（RIFE VFI）。只认前者会在 RIFE 上静默返回空。
  - RIFE 权重自动选**版本号最大**的：`_rife_rank()` 解析 `rife(\d)(\d{1,2})\.pth`
    （rife49→409 < rife417→417 < rife426→426）→ 本机改用 rife426（原死守 rife49）。
- **新增 `quality_probe.py`**：VMAF/PSNR/SSIM 客观度量（ffmpeg 自带 libvmaf，已验证可用）。
  两侧自动 scale+format 对齐；`--max-sec` 只比片段。判读阈值表见 `_THRESHOLDS`。
  实测：自比 VMAF 98.1（无损）/ crf38 劣化片 65.9（明显劣化）→ 能真实区分。
  - 坑：`average:inf` 表示两片逐像素相同（自比时必现），正则要吃 `inf`。
  - 坑：VMAF 日志用 tempfile 时，`finally` 清理会**先于** `_parse` 执行 → 必须在解析**之后**删。
  - 坑：Windows 路径里冒号会破坏 ffmpeg 滤镜参数 → 日志用**相对文件名 + cwd**。
- **新增 `--loudnorm`**（EBU R128, -16 LUFS / TP -1.5）：多集发布时响度一致
  （平台会再归一化，各集不一致会被压得忽大忽小）。
- 测试：`tests/test_quality_tooling.py`（18 例，全离线）。`pytest -q` **466 passed** / ruff clean。

  - 现象①：`launch_comfy.py` 输出 `did not find executable at 'D:\Program\python.exe'`，`comfy_run.log` 仅 68 字节。
    根因：`D:/ComfyUI/venv/pyvenv.cfg` 的 base 是 `D:\Program\python.exe`（3.13.15），而沙箱把 `D:\Program` 改名成
    `D:\Program.backup`；`D:/Program.backup/python.exe` 虽在，但其 prefix 也指向 `D:\Program`，**独立跑同样 `Failed to import encodings`**。
  - **修法（可回滚）**：备份 `pyvenv.cfg`→`.bak`，把 `home`/`executable` 指向 `C:\Users\michael\.workbuddy\binaries\python\versions\3.13.12`，

    `Starting server` **无报错**。根因：**沙箱回收 detach 的子进程**（`DETACHED_PROCESS` 挡不住进程树回收）。
    → 改为把 ComfyUI 作为**常驻后台任务**跑（`run_in_background`）：直接

    cwd=`D:/ComfyUI`、清空 `PYTHONPATH`、`TORCH_COMPILE_DISABLE=1`、带 `NO_PROXY`。**16s READY** 且稳定。
  - 现象③：所有对 `127.0.0.1:8188` 的探测先返回 **502 Bad Gateway** —— env 里 `HTTP_PROXY=127.0.0.1:13761` 且 `NO_PROXY` 为空，

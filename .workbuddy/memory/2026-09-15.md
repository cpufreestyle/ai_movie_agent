## WebUI 主题化改造（亮/暗 · 密度 · 强调色 · 导航分组）+ 修复 <style> 未闭合 bug
- 起因：用户选「全部四项」——亮/暗切换、页签布局、间距密度、主题色。
- **修复真 bug**：上一批美化层用 `</style>\n</head>` 做替换时把原 `<style>` 的闭合标签一并吞掉 → 页面变成 2 个 `<style>` 开标签 / 1 个闭标签，favicon 被关进样式里失效、`id=ui-aesthetic` 名不副实（浏览器容错所以视觉正常）。修法：在 `<link rel="icon">` 前补回 `</style>`。timeline.html 当时 new_string 带了 `</style>`，无此问题。
- 新增 `<style id="ui-theming">`（pipeline.html）：
  - 亮/暗：`html[data-theme=light]` 覆盖 `--bg/--surface/--surface2/--line/--fg/--mut/--green/--red/--shadow`，并覆盖硬编码色（`.stage-head/.ep-head:#171c22→#f3f7fc`、input/textarea/select/`.chip:#151a20→白`、`pre:#0d1014/#cdd8e1→浅`、video 保持黑底、header h1 渐变改深、滚动条、hover 叠加改 `rgba(0,0,0,*)`）。
  - 强调色：`html[data-accent=*]` 驱动 `--blue`（blue/green/purple/amber/pink/cyan）；nav 激活渐变用 `color-mix`（不支持则回退旧渐变）。
  - 密度：`html[data-density=compact]` 收紧 main/topbar/stage/panel/nav 间距，默认「舒适」。
  - 导航：`nav{position:sticky;top:0;z-index:30}` + `@supports` 半透明毛玻璃；`.nav-sep` 分隔线把 9 个页签分成 4 组（制作/阶段/产出/设置）。
  - 外观控件：头部 `.appearance`（`.seg` 分段按钮 ×2 + `.swatches` 色板 ×6）。
- 防闪烁：`<head>` 内早期脚本读 localStorage `ui-theme/density/accent` 设 `data-*`；切换后写回并同步 `.on` 高亮。
- timeline.html：加 `ui-theme` 块 + 早期脚本，跟随主应用偏好（读同一 `ui-*` key，无自带控件）。
- 坑：色板初版把颜色写在 `data-c` 上用 `var(--c)` → CSS 读不到（`attr()` 不能用于 background），改内联 `style="--c:#..."`。

## 安装浏览器自动化 + WebUI 端到端自测（agent-browser）
- 装法（隔离，不污染全局）：`node <npm-cli.js> install agent-browser --prefix C:/Users/michael/.workbuddy/binaries/node/workspace --registry https://registry.npmmirror.com`。npm 用托管 node 直调 `node_modules/npm/bin/npm-cli.js`（PATH 上的 `npm` shim 会乱码并触发 wsl 黑名单）。
- **关键：不自带 Chromium**（`agent-browser install` 从 Google CDN 下载慢/易卡）→ 改指向系统 Chrome：`export AGENT_BROWSER_EXECUTABLE_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe"`，并 `export NO_PROXY=127.0.0.1,localhost`（否则 localhost 走代理 502）。CLI 入口：`node <ws>/node_modules/agent-browser/bin/agent-browser.js <cmd>`。
- **坑**：① 不要把命令写成 `.sh` 用 `bash` 跑（shim 触发 wsl.exe 黑名单，整条失败）；用**内联命令**。② agent-browser 会话在同一 Bash 调用内持久（daemon），**跨 Bash 调用不保证**——有状态交互（open→click→截图）必须在**同一次**调用里完成，否则在空白页点击报「Element not found」。③ 输出含 ANSI，重定向成日志后会被判二进制；写个小工具 strip `\x1b\[...` 再读。
- **端到端测试结论（全绿）**：9 个页签逐一 `click nav button[data-tab=…]` 后 `nav button.active` 均正确切换；主题：清 localStorage 后 `data-theme=null`/body `rgb(17,20,24)`（默认暗），点「亮」→ `light`/`rgb(238,241,246)` 且写入 localStorage，切回「暗」恢复；密度 compact → `main` padding `12px`；强调色 purple → 导航激活渐变变 `#8b5cf6`（`color-mix` 生效）；`/timeline` 自动跟随为 light；`errors`/`console` 均为空（**无 JS 报错**）。
- **visual 校验法（重要）**：不要靠肉眼判断截图主题——本地 Read 图片渲染会给了陈旧/错误画面，误判成「浅色」。改用 Pillow 测平均亮度：暗≈(29,35,41)，亮≈(243,245,248)；并用 md5 比对截图是否真变。据此确认默认暗、切换生效（我一度据此纠正了误判）。

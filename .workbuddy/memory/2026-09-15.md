## 专业选项「悬停解释」tooltip（webui/pipeline.html）
- 需求：专业选项（白模模块 + 设置页阶段选择）鼠标悬停时弹解释。
- **实现方案（避免 overflow 裁剪，优于纯 CSS `::after`）**：单一浮层 `#ui-tip`（`position:fixed`，`z-index:2147483000`，`pointer-events:none`，`white-space:pre-wrap`）由 JS 按 `[data-tip]` 定位；`document` 级 `mouseover/mouseout/focusin/focusout` 事件委托，`closest('[data-tip]')` 取最近目标；越界自动左/上翻边（`getBoundingClientRect` + `offsetWidth`）。
- 视觉可发现性：内容文本包 `<span class="tip" data-tip="…">`，加虚线下划线 + 圆形「?」小徽标，hover 变主题色；`[data-tip]{cursor:help}`。
- **关键可用性修正**：只给 `<span>` 加 `data-tip` 时，悬停 `<select>`/`<input>` 本体不触发（实测 light 主题 hover `#blk-engine` 时 `#ui-tip` 类名为空）。修法：IIFE 里把 `span.tip[data-tip]` 的值**复制到外层 `<label>`**（仅当父级是 LABEL 且自身无 data-tip），DOM 中 `[data-tip]` 元素 23→45，整块控件区都可触发。
- 多行文案用 HTML 实体 `&#10;` 写在属性里（源文件保持单行，浏览器解析成真换行 + pre-wrap 渲染）。
- 覆盖范围：白模模块 6 个参数 + 4 个开关 + 开关组标题 + 分镜文本 + 渲染模式；设置页 A~H 共 10 个阶段档案选择器。合计 23 处 `data-tip`。
- 验证：HTMLParser 0 错误、无未闭合；`<style>` 3/3、ui-theming 花括号 64/64；服务端 200 且已含新标记；agent-browser 逐页签切换 `errors` 为空；暗/亮主题各 hover 截图确认浮层渲染与可读性。

## **CI 其实已经红了好几轮** —— 修掉两层串联的隐藏失败（commit d01f900 + 8b19ca7）
> 教训：CI 的「lint 绿」是假象，前一步失败会让后一步 `skipped`，看板只显示整体红但没人知道测试压根没跑。

### 第一层：`.gitignore` 的 `_*.py` 把 `__init__.py` 一起吃掉了
- 症状：spoke 脚本步骤报 `ImportError: cannot import name 'register_blueprints' from 'webserver' (unknown location)`。
- 根因：`_*.py` 里的 `*` 能匹配 `_init`，于是 **`webserver/__init__.py` / `services/__init__.py` / `views/__init__.py` 三个包声明文件从未入库**；本地磁盘上有所以一直绿，只有全新克隆才炸。`webserver/__init__.py` 正是导出 `register_blueprints` 的地方。
- 修法：在 `_*.py/_*.ps1/_*.bat/_*.txt` 之后加 `!**/__init__.py` 显式取反（其余 46 个 `_*` 一次性脚本仍照常忽略）；`git add` 补入三个文件。
- **复查法**：`git check-ignore -v <path>` 逐个确认；别只看 `git status`（被忽略的文件根本不出现）。
